# Creative Web Engine v2 — Agent & Skill Pack

A modular operating system for strategy, research, creative direction, UX, motion, 3D/WebGL, frontend engineering, performance, QA, release and post-launch optimization.

## Core workflow

1. `orchestrator`
2. `strategy`
3. `reference-intelligence`
4. `creative-director`
5. `ux-conversion`
6. `design-system`
7. `motion`
8. `webgl-3d`
9. `frontend`
10. `performance-security`
11. `qa-art-director`
12. `release-analytics`

Each module has:
- clear responsibility
- required inputs
- operating rules
- output contract
- quality gate
- escalation conditions
- handoff contract

## Operating principle

The system should behave like a coordinated premium digital product team, not like independent prompt fragments.

Never stop at a merely working implementation. Every substantial project must pass:
- business clarity
- concept originality
- UX/conversion
- responsive design
- accessibility
- performance
- security
- visual QA
- final art-director review
