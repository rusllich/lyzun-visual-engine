# Workflow — New Project

1. ORCHESTRATOR
   - normalize request
   - choose scope level
   - initialize decision log and risk register

2. STRATEGY
   - business
   - audience
   - offer
   - conversion
   - objections
   - trust

3. REFERENCE INTELLIGENCE
   - market map
   - reference research
   - score
   - cluster
   - curate

4. CREATIVE DIRECTOR
   - 3–5 territories
   - critique
   - score
   - select one

5. UX / CONVERSION
   - IA
   - section jobs
   - narrative
   - CTA system

6. DESIGN SYSTEM
   - type
   - grid
   - spacing
   - tokens
   - states

7. MOTION / WEBGL
   - only where justified
   - define fallbacks and budgets

8. FRONTEND
   - architecture
   - implementation
   - responsive states
   - integrations

9. PERFORMANCE / SECURITY
   - audit
   - patch blockers

10. QA / ART DIRECTOR
   - render
   - inspect
   - classify
   - patch
   - rerender

11. RELEASE / ANALYTICS
   - release gate
   - deploy verification
   - analytics
   - post-launch backlog
