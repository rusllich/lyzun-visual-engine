# Workflow — Existing Project

1. Audit current architecture and visual system.
2. Preserve strong work.
3. Identify:
   - P0 broken production issues
   - P1 UX/conversion/responsive/security issues
   - P2 visual inconsistency
   - P3 polish
   - P4 experiments
4. Route each issue to the owning specialist.
5. Implement root-cause fixes.
6. Build and validate.
7. Run visual/responsive/accessibility/performance/security QA.
8. Run final art-director pass.
9. Release only after the gate is satisfied.
