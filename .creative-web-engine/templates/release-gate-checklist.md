# Release Gate Checklist

## Business
- [ ] Value proposition is clear.
- [ ] Primary CTA is clear.
- [ ] Trust is sufficient.
- [ ] Major objections are addressed.

## Creative
- [ ] Concept is distinctive.
- [ ] First screen is strong.
- [ ] Composition is original.
- [ ] Typography is coherent.
- [ ] Imagery is coherent.
- [ ] Motion is meaningful.
- [ ] 3D is meaningful where present.

## UX
- [ ] Navigation is clear.
- [ ] Conversion path is clear.
- [ ] Mobile is intentionally designed.
- [ ] Forms and critical states are usable.

## Engineering
- [ ] Architecture is maintainable.
- [ ] No critical build/runtime errors remain.
- [ ] No secrets are exposed.
- [ ] Integrations are validated.

## Performance
- [ ] Core performance is acceptable.
- [ ] Target mobile behavior is acceptable.
- [ ] Media and WebGL are optimized.
- [ ] Fallback behavior is present.

## Accessibility
- [ ] Keyboard navigation works.
- [ ] Focus states are visible.
- [ ] Heading hierarchy is correct.
- [ ] Reduced-motion support exists.
- [ ] Contrast and touch targets are acceptable.

## QA
- [ ] P0 issues resolved.
- [ ] P1 issues resolved.
- [ ] Major P2 issues resolved.
- [ ] Visual QA completed.
- [ ] Mobile art-director pass completed.
- [ ] Final art-director review completed.
